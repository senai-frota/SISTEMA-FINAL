# Frontend — FROTA-SENAI

Interface React (Vite) do sistema de frota.

Documentação completa: [docs/](../docs/).

## Comandos

```bash
npm install
npm run dev
npm run build
npm run preview
```

Sem `VITE_API_URL`, a base da API é resolvida automaticamente (localhost ou mesmo host na porta `8000`). Detalhes em [docs/configuracao.md](../docs/configuracao.md).
